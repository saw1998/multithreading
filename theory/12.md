PART 5: DEADLOCKS — COMPLETE UNDERSTANDING
5.1 The Four Coffman Conditions

```cpp
DEADLOCK requires ALL FOUR of these conditions:

1. MUTUAL EXCLUSION
   At least one resource cannot be shared
   (Bathroom key: only one person at a time)

2. HOLD AND WAIT
   Thread holds at least one resource and WAITS for another
   (Chef holds knife, waits for cutting board)

3. NO PREEMPTION
   Resources cannot be forcibly taken from a thread
   (Can't grab the knife from the chef's hand)

4. CIRCULAR WAIT
   A cycle: A waits for B, B waits for C, C waits for A
   (Chef A waits for Chef B's pan,
    Chef B waits for Chef C's knife,
    Chef C waits for Chef A's cutting board)

SOLUTION: Break ANY ONE of these four conditions!
```
