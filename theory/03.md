ANALOGY: A Company

PROCESS = A Company (Microsoft Word)
│
├── Has its OWN office building (memory space)
├── Has its OWN employees, furniture, resources
├── Cannot easily access another company's resources
└── Starting a new company is EXPENSIVE and SLOW

THREAD = An Employee in that company
│
├── Shares the SAME office building (same memory)
├── Can access the SAME resources (shared data)
├── Lightweight — cheap to create
└── Can cause CONFLICTS when accessing shared resources

│                         PROCESS                              │

│  └──────────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────────────┘

EACH THREAD HAS:              THREADS SHARE:
- Its own stack               - Heap memory
- Its own registers           - Global variables
- Its own program counter     - File handles
- Its own local variables     - Static variables
                              - Code (instructions)
