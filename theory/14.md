PART 6: CONDITION VARIABLES — WAITING EFFICIENTLY
6.1 The Problem — Busy Waiting

```cpp
SCENARIO: Producer-Consumer

Without condition variables, consumer must BUSY WAIT:

Consumer:
  while (queue.empty()) { }  // keep checking... 
  // This is called SPINNING or BUSY WAITING!

PROBLEMS WITH BUSY WAITING:
1. Wastes 100% of CPU doing nothing useful
2. Prevents other threads from running (on single-core)
3. Increases heat, power consumption
4. Unfair to other threads

WHAT WE WANT:
Consumer goes to SLEEP when queue is empty.
Producer WAKES UP consumer when it adds an item.

This is EXACTLY what condition variables do!
```
