PART 12: LATCHES AND BARRIERS — THREAD SYNCHRONIZATION POINTS
12.1 What Are Latches and Barriers?

LATCH: "Wait until N things complete, then everyone continues"

REAL WORLD: Starting gun at a race
- All runners line up (N threads wait)
- Official fires gun (count reaches 0)
- ALL runners start simultaneously

OR: Waiting for all prerequisite tasks to complete
- Load config file    ↘
- Connect to database  → LATCH → Continue when all 3 done
- Initialize cache    ↗

BARRIER: "Synchronize ALL threads at this point, then continue"

REAL WORLD: Military march
- All soldiers must reach the checkpoint before any continue
- "Ready? Ready? Ready? OK everyone move to next checkpoint"

Used in: parallel algorithms where each "round" requires all
         threads to finish before the next round begins.

DIFFERENCE:
- Latch: single-use countdown (one-shot)
- Barrier: reusable (threads synchronize repeatedly)
