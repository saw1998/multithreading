PART 10: FUTURES, PROMISES, AND ASYNC — RESULT-BEARING THREADS
10.1 The Problem — How to Get Results from Threads?

```cpp
PROBLEM:
  std::thread has no way to return a value!
  
  int result = 0;
  std::thread t([&result]() {
      result = expensiveComputation(); // set shared variable
  });
  t.join();
  use(result); // ← works but requires shared variable + manual sync
  
  THIS IS UGLY AND ERROR-PRONE!

SOLUTION: Future/Promise pattern
  "Promise" = commitment to provide a value later
  "Future" = a handle to retrieve that value when it's ready
  
  Like ordering a package online:
  - Order confirmation = Promise (they promise to deliver)
  - Tracking number = Future (you can check status anytime)
  - Delivery = when future.get() returns
```
