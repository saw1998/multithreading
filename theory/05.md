What happens when you create a thread?

std::thread t(myFunction, arg1, arg2);

WHAT THE OS DOES INTERNALLY:

1. ALLOCATES A STACK
   ┌────────────────────────────────────────┐
   │ OS asks CPU: "give me 1-8MB of memory" │
   │ This becomes the thread's private stack│
   └────────────────────────────────────────┘

2. CREATES A THREAD CONTROL BLOCK (TCB)
   ┌────────────────────────────────────────┐
   │ TCB stores:                            │
   │  - Thread ID                           │
   │  - State (running/waiting/ready)       │
   │  - Stack pointer                       │
   │  - Program counter (where to start)   │
   │  - Priority                            │
   │  - CPU registers                       │
   └────────────────────────────────────────┘

3. ADDS TO SCHEDULER QUEUE
   The OS Scheduler decides WHEN this thread runs

4. CPU CONTEXT SWITCH (when thread starts/pauses)
   ┌────────────────────────────────────────┐
   │ 1. Save all registers of current thread│
   │ 2. Load registers of new thread        │
   │ 3. Jump to new thread's instruction    │
   │ This takes ~1-10 microseconds          │
   └────────────────────────────────────────┘
