PROBLEM 1: SLOW I/O BLOCKING EVERYTHING

Single-threaded program:

Time →  0s        1s        2s        3s        4s
        ├─────────┼─────────┼─────────┼─────────┤
        │  Work   │ WAITING │ WAITING │  Work   │
        │  code   │  for    │  for    │  code   │
        │  runs   │  disk   │ network │  runs   │
        │         │  read   │response │         │
                    ^                  ^
                    CPU is IDLE here! Wasted!

Multi-threaded program:

Thread 1: ├── Work ──┤ WAIT │ WAIT │── Work ──┤
Thread 2:            ├── Work while T1 waits ─┤
Thread 3:                 ├── More work ──────┤

Result: 4x faster! CPU always doing something useful!

PROBLEM 2: NOT USING ALL CPU CORES

Modern CPUs have 8, 16, 32 cores
Single-threaded: uses 1 core = 1/16th of power
Multi-threaded: uses all 16 cores = full power

PROBLEM 3: RESPONSIVENESS
Single-threaded GUI: if computing for 5s, UI freezes
Multi-threaded: UI thread always responsive, compute in background

WHAT MULTI-THREADING SOLVES:
1. ⚡ Performance: Use multiple CPU cores in parallel
2. 🔄 I/O efficiency: Don't waste CPU while waiting for disk/network
3. 📱 Responsiveness: Keep UI alive while computing
4. 🌐 Scalability: Handle many requests simultaneously (servers)
