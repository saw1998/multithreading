PART 8: READER-WRITER LOCKS — COMPLETE IMPLEMENTATION
8.1 Why Reader-Writer Locks?

SCENARIO: In-memory cache with 1000 reads per second, 1 write per second

WITH REGULAR MUTEX:
- EVERY read waits for every other operation
- 1000 reads must be SERIALIZED (one at a time)
- Total throughput: 1000 reads/sec but serialized
- Reads take 10ms each: total time = 10 seconds!

WITH READER-WRITER LOCK:
- Reads happen CONCURRENTLY
- All 1000 reads can run SIMULTANEOUSLY
- Total time: 10ms (all reads overlap)
- 1000x speedup!

The insight: reads don't interfere with each other.
Two threads reading the same variable at the same time is SAFE.
Only write-write or read-write combinations are dangerous.
