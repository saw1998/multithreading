KEY INSIGHT:
Each CPU Core has its OWN cache (L1)
When Core 1 reads 'counter', it copies to its own L1 cache
When Core 2 reads 'counter', it copies to ITS own L1 cache
Now BOTH cores have a SEPARATE COPY of the same variable!
If Core 1 changes its copy, Core 2 doesn't automatically see it!
THIS IS WHERE DATA RACES COME FROM
